# 흉부 X-ray 소견 탐지 모델 평가

## 평가 목적
심비대·폐부종·흉수에 대한 예측 성능을 평가하고,
단일·복합 소견별 성능과 오분류 사례를 분석한다.

현재는 DenseNet121 + U-MultiClass 모델의 저장된 가중치를 불러와,
실제 X-ray 영상으로 구성된 pilot 테스트 데이터 100장에 대해 평가한다.
평가 노트북에서 직접 예측 결과를 생성하여 지표 계산과 결과 분석을 수행한다.

현재 결과는 pilot 평가 결과이며, 최종 학습 모델의 평가 결과와 구분한다.
최종 평가에는 학습·검증 데이터와 환자가 중복되지 않는 테스트 데이터를 사용한다.

## 라벨 및 데이터 규칙
- 소견 순서: 심비대 → 폐부종 → 흉수
- 클래스 코드: 0=음성, 1=양성, 2=불확실
- 데이터 선정 단계에서 세 소견이 모두 결측값인 이미지는 제외한다.
- 나머지 이미지의 결측값은 0으로 처리한다.
- 원본의 불확실 레이블(-1)은 Dataset에서 클래스 코드 2로 변환한다.
- 결측값에서 변환된 음성 라벨이 포함된다는 점을 결과 해석에 고려한다.

| 변수 | 내용 | 형태 |
|---|---|---|
| `y_true` | 실제 정답 코드 | (이미지 수, 3) |
| `y_prob` | 소견별 음성·양성·불확실 확률 | (이미지 수, 3, 3) |
| `y_pred` | 각 소견에서 가장 높은 확률의 클래스 | (이미지 수, 3) |

평가 노트북에서 저장된 모델과 test DataLoader를 사용해
전체 테스트 이미지의 정답·예측 확률·예측 클래스를 수집한다.
수집한 결과는 이미지 ID(`dicom_id`)와 함께 `predictions_test.npz`로 저장한다.

정답과 예측 데이터의 이미지 순서 및 소견 순서는 같아야 한다.
예측 확률은 소견별로 합이 1이어야 하며,
`y_pred`는 `y_prob`의 최댓값 클래스와 일치해야 한다.

## 소견별 평가 기준
- 음성·양성·불확실을 모두 포함해 precision, recall, F1-score를 계산한다.
- 혼동행렬의 행은 실제 정답, 열은 모델 예측이다.
- 클래스 순서는 음성 → 양성 → 불확실로 고정한다.
- 계산이 불가능한 precision·recall·F1은 `zero_division=0`에 따라 0으로 표시한다.
- 정답 사례가 없는 클래스의 성능은 해당 데이터로 확인할 수 없으며,
  이 클래스의 0점도 macro 평균에 포함된다.

## 양성 AUROC 평가 기준
각 소견에 대해 동일한 정답·예측 데이터를 사용하여
두 방식의 AUROC를 계산한다.

### 공통 기준
- 해당 소견의 정답이 음성(0) 또는 양성(1)인 사례만 사용한다.
- 해당 소견의 불확실 정답(2)은 제외한다.
- 정답이 음성·양성이면 모델이 불확실로 예측했어도 평가에 포함한다.
- 음성과 양성이 모두 존재하지 않으면 AUROC를 NaN으로 표시한다.

### 1. 양성·음성 정규화 AUROC — 주 평가
- 양성·음성 사이의 상대적인 점수를 사용한다.
- 계산식: 양성 확률 / (음성 확률 + 양성 확률)
- 음성 확률과 양성 확률의 합이 0인 사례가 있으면
  해당 소견의 정규화 AUROC를 NaN으로 표시한다.
- 이 점수는 불확실 확률을 포함한3클래스 양성 확률과 구분한다.

### 2. 3클래스 양성 확률 AUROC — 보조 평가
- 음성·양성·불확실의 3클래스 확률 중 양성 확률을 그대로 사용한다.
- 정규화 방식과 비교하기 위한 보조 지표로 보고한다.

두 방식의 AUROC는 구분하여 함께 보고한다.
3클래스 F1-score와 혼동행렬에서는 불확실 클래스를 계속 포함한다.

## AUPRC 평가 기준
- 해당 소견의 정답이 음성(0) 또는 양성(1)인 사례만 사용한다.
- 양성·음성 정규화 점수로 Precision–Recall 곡선을 구성한다.
- `auc(recall, precision)`으로 사다리꼴 적분 AUPRC를 계산한다.
- Average Precision(AP)과 구분하여 보고한다.
- 음성과 양성 중 하나라도 없거나 정규화 분모가 0인 사례가 있으면 NaN으로 표시한다.
- 평가 대상 수와 양성 비율을 함께 보고한다.

## 추가 양성 탐지 지표: Sensitivity·Specificity·AP
- 해당 소견의 정답이 음성(0) 또는 양성(1)인 사례만 사용하고,
  불확실 정답(2)은 제외한다.
- **Sensitivity(민감도)**: 실제 양성 중 양성으로 예측한 비율 `TP / (TP + FN)`.
  - 실제 양성을 음성 또는 불확실로 예측하면 FN으로 계산한다.
- **Specificity(특이도)**: 실제 음성 중 음성으로 예측한 비율 `TN / (TN + FP)`.
  - 실제 음성을 양성 또는 불확실로 예측하면 FP로 계산한다.
  - 따라서 이 지표는 불확실 예측을 오답으로 처리하는
    **3클래스 기반의 보수적 정의**이며, 일반적인 이진분류 특이도와 구분한다.
- 분모가 0이면 해당 민감도 또는 특이도를 NaN으로 표시한다.
- **Average Precision(AP)**: `average_precision_score()`로 계산하며,
  정규화 점수가 아닌 **원본 3클래스 양성 확률**을 사용한다.
- AP는 평가 정답에 음성과 양성이 모두 존재할 때 계산하고,
  그렇지 않으면 NaN으로 표시한다.
- AUPRC(정규화 점수의 사다리꼴 적분)와
  AP(원본 양성 확률의 Average Precision)는
  **점수와 계산 방식이 모두 다르므로** 명칭을 구분하여 보고한다.

참고: [CheXpert 원 논문](https://arxiv.org/abs/1901.07031)

## 단일·복합 소견 비교 기준
세 소견의 정답에 불확실(2)이 없는 이미지만 사용한다.
실제 양성 소견 개수를 기준으로 다음 그룹으로 구분한다.

- 양성 소견 0개
- 단일 소견: 양성 1개
- 복합 소견: 양성 2~3개

그룹별로 다음 지표를 계산한다.

- 세 소견 모두 정답 비율: 이미지의 세 소견을 모두 맞힌 비율
- 소견별 판단 정확도: 그룹 내 전체 소견 판단 중 맞힌 비율

예측이 불확실이면 음성·양성 정답과 다르므로 오답으로 계산한다.
그룹에 이미지가 없으면 평가 지표를 NaN으로 표시한다.

단일·복합 구분은 대상 소견 3개 안에서의 구분이며,
양성 소견 0개가 다른 질환까지 없는 정상 이미지를 의미하지는 않는다.

## 결과 시각화 기준
- 소견별 3×3 혼동행렬을 히트맵으로 표시한다.
- 단일·복합 소견 그룹별 세 소견 모두 정답 비율과
  소견별 판단 정확도를 막대그래프로 비교한다.
- 해당 그룹에 평가 대상이 없으면 지표는 NaN이며,
  그래프의 빈 항목을 성능 0으로 해석하지 않는다.

## 오분류 분석 기준
- 정답 코드와 예측 코드가 다른 소견을 기록한다.
- 한 이미지에서 여러 소견을 틀리면 소견별로 각각 기록한다.
- 소견별 오분류 개수와 실제 정답 → 모델 예측 유형을 요약한다.
- 현재 오분류 표의 이미지 번호는 test CSV 행 순서 기준의
  1부터 시작하는 번호이다.
- `predictions_test.npz`에 같은 순서로 저장된 `dicom_id`와 연결하여
  원본 이미지를 확인한다.
- 향후 오분류 표에도 `dicom_id` 또는 이미지 경로를 직접 포함한다.

## 평가 결과 저장
모델 실행 폴더명별로 결과를 저장한다.

- `predictions_test.npz`: 정답, 예측 확률, 예측 클래스, 이미지 ID
- `auroc.csv`: 소견별 원본·정규화 AUROC
- `auprc.csv`: 소견별 정규화 AUPRC와 평가 대상의 양성 비율
- `additional_metrics.csv`: 소견별 민감도·특이도·AP
- `finding_groups.csv`: 단일·복합 소견 그룹별 평가 결과
- `misclassifications.csv`: 소견별 오분류 목록
- `classification_reports.json`: 소견별 precision·recall·F1-score 등
- `confusion_matrix.png`: 소견별 혼동행렬
- `finding_groups.png`: 단일·복합 소견 그룹별 성능 비교 그래프
- `evaluation_info.json`: 모델 경로, 데이터 경로, 평가 이미지 수,
  저장 당시 epoch, 소견·클래스 순서 등 평가 설정

## 평가 및 결과 해석 시 확인사항
- 현재 실행 결과는 pilot 테스트 이미지 100장을 대상으로 하며,
  최종 평가 결과와 구분한다.
- Train/Validation과 Test 간 환자 중복 여부를 확인한다.
- 소견별 불확실 정답 제외로 AUROC·AUPRC·AP의 평가 대상 수가 달라질 수 있다.
- 단일·복합 소견 비교에서는 세 소견 중 불확실 정답이 하나라도 있는 이미지를 제외한다.
- 지표가 NaN이거나 그룹이 비어 있으면 클래스 구성과 제외 기준을 확인한다.
- 이미지별 오분류를 원본 X-ray와 연결할 수 있도록
  이미지 ID와 예측 결과의 순서를 유지한다.
- 정규화 AUROC(주 평가)와 원본 양성 확률 AUROC(보조 평가),
  AUPRC와 AP의 정의를 구분하여 보고한다.
- 모델 경로, 테스트 CSV, 평가 이미지 수, 소견·클래스 순서 등
  평가 설정을 결과와 함께 저장한다.
