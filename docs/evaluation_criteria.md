# 흉부 X-ray 소견 탐지 모델 평가 기준

## 1. 평가 목적 및 데이터

심비대·폐부종·흉수의 예측 성능을 평가하고, 단일·복합 소견별 성능과 오분류 사례를 분석한다. 이 문서는 수정된 `cxr_evaluation.ipynb`의 평가·저장 기준을 따른다.

- 선택한 실험의 저장된 가중치를 불러와 테스트 이미지에 직접 추론한다.
- 현재 테스트 CSV는 `data/processed/pilot/pilot_test.csv`이며, 평가 이미지 수는 해당 CSV를 기준으로 결정된다.
- 학습과 동일한 전처리를 적용하고, 체크포인트의 입력 크기를 사용한다.
- `DataLoader`는 `shuffle=False`, `drop_last=False`로 구성하여 CSV와 예측 결과의 순서 및 개수를 유지한다.
- 이미지 누락을 확인하고, 임시 데이터 학습을 의미하는 `smoke_test=True` 체크포인트는 평가를 중단한다.
- pilot 평가 결과는 최종 평가와 구분한다. 최종 평가는 Train/Validation과 환자가 중복되지 않는 독립된 Test 데이터에서 수행한다.

## 2. 비교 실험

| 실험 | 모델 | 불확실 라벨 처리 | 비교 목적 |
| --- | --- | --- | --- |
| ① 기준 | DenseNet121 | U-multiclass | 기준 실험 |
| ② 모델 비교 | ResNet50 | U-multiclass | ①과 비교하여 모델 구조의 효과 확인 |
| ③ 라벨 처리 비교 | DenseNet121 | U-ignore | ①과 비교하여 불확실 라벨 처리 방식의 효과 확인 |

- 모델 종류 비교는 ①과 ②, 라벨 처리 방식 비교는 ①과 ③을 대상으로 한다.
- 세 실험은 동일한 테스트 데이터, 전처리 설정, 평가 대상 선정 규칙을 사용한다.
- `MODEL_NAME`, `UNCERTAINTY_STRATEGY`, `MODEL_PATH`를 선택한 학습 결과에 맞춰 설정하고 실험별로 개별 실행한다.
- 실험 이름은 `<모델 이름>_<라벨 처리 방식>`으로 구성한다.

## 3. 라벨 및 입력 데이터 규칙

- 소견 순서: 심비대(`Cardiomegaly`) → 폐부종(`Edema`) → 흉수(`Pleural Effusion`).
- 평가 정답 코드: `0=음성`, `1=양성`, `2=불확실`.
- 데이터 선정 시 세 소견이 모두 결측인 이미지는 제외하고, 나머지 결측값은 0으로 처리하는 기존 기준을 유지한다.
- 원본 불확실 라벨 `-1`은 평가 시 코드 `2`로 변환하여 보존한다. U-ignore 실험에서도 테스트 정답의 불확실을 음성으로 바꾸지 않는다.
- 결측값에서 변환된 음성 라벨이 포함된다는 점을 결과 해석에 고려한다.
- 정답·예측·`dicom_id`의 이미지 순서와 소견 순서는 일치해야 한다.

`N`은 테스트 이미지 수다.

| 변수 | 내용 | U-multiclass | U-ignore |
| --- | --- | --- | --- |
| `y_true` | 음성·양성·불확실 정답 | `(N, 3)` | `(N, 3)` |
| `y_prob` | 모델의 확률 출력 | `(N, 3, 3)` | `(N, 3)` |
| `y_pred` | 모델 자체 예측 | 3클래스 확률의 argmax, `(N, 3)` | 공통 이진 예측과 동일, `(N, 3)` |
| `y_score` | 공통 평가용 양성 점수 | `(N, 3)` | `(N, 3)` |
| `y_pred_binary` | 공통 평가용 음성·양성 예측 | `(N, 3)` | `(N, 3)` |

U-multiclass의 클래스 순서는 음성 → 양성 → 불확실이며, 소견별 softmax 확률 합은 1이다. U-ignore는 소견별 sigmoid 확률을 사용하므로 세 소견의 확률 합이 1일 필요가 없다. 확률과 공통 양성 점수는 유한한 0~1 값이어야 한다.

## 4. 공통 양성 점수 및 이진 판정

| 라벨 처리 방식 | `y_score` 계산 기준 |
| --- | --- |
| U-multiclass | `양성 확률 / (음성 확률 + 양성 확률)` |
| U-ignore | 각 소견의 `sigmoid(logit)` 양성 확률 |

U-multiclass의 공통 점수는 음성·양성 logit 두 개에만 softmax를 적용하여 계산한다. 이는 위 정규화 식과 수학적으로 같으며, 저장된 확률을 직접 나눌 때 생길 수 있는 수치적 문제를 줄인다.

- 공통 이진 판정: `y_pred_binary = (y_score >= THRESHOLD)`.
- 기본 `THRESHOLD`는 `0.5`이며, 점수가 기준값 이상이면 양성(1), 미만이면 음성(0)이다.
- 기준값을 변경할 경우 검증 데이터에서 결정하고 평가 정보에 기록한다. 테스트 결과를 보고 기준값을 선택하지 않는다.
- U-multiclass의 `y_pred`가 불확실이어도 공통 이진 평가는 `y_score`와 `y_pred_binary`로 수행한다.

## 5. 소견별 공통 이진 평가

각 소견에서 정답이 음성(0) 또는 양성(1)인 항목만 사용하고, 해당 소견의 불확실 정답(2)은 제외한다. 다른 소견이 불확실하다는 이유로 해당 항목까지 제외하지 않는다.

### Precision·Recall·F1 및 혼동행렬

- `y_true`와 `y_pred_binary`로 음성·양성의 Precision, Recall, F1-score, support를 계산한다.
- 클래스 순서는 음성 → 양성으로 고정한다.
- 혼동행렬은 2×2이며, 행은 실제 정답, 열은 모델 예측이다.
- 소견별 평가 이미지 수와 불확실 정답 제외 수를 함께 출력한다.
- 평가 가능한 정답이 없으면 분류 보고서와 혼동행렬 계산을 건너뛰고, 저장 보고서는 `null`로 기록한다.
- Precision·Recall·F1 계산이 불가능한 경우 `zero_division=0`에 따라 0으로 표시한다.
- 분류 보고서의 macro 평균은 해당 소견의 음성·양성 클래스 점수를 동일한 비중으로 평균한 값이다. 세 소견 간 평균과 구분한다.
- 정답 사례가 없는 클래스의 성능은 확인할 수 없으며, 해당 클래스의 0점도 고정된 클래스 목록의 macro 평균에 포함된다.

### AUROC·AP·AUPRC

세 지표 모두 동일한 평가 대상과 공통 양성 점수 `y_score`를 사용한다.

| 지표 | 계산 방식 | 결과표 이름 |
| --- | --- | --- |
| AUROC | `roc_auc_score(true_binary, positive_score)` | `공통 AUROC` |
| AP | `average_precision_score(true_binary, positive_score)` | `AP` |
| AUPRC | `precision_recall_curve()` 이후 `auc(recall, precision)` | `공통 AUPRC (사다리꼴)` |

- 현재 코드에서는 평가 정답에 음성과 양성이 모두 존재할 때 계산하며, 그렇지 않으면 `NaN`으로 표시한다.
- AUROC·AP·AUPRC는 `THRESHOLD`의 영향을 받지 않는다.
- AP와 사다리꼴 AUPRC는 같은 점수를 사용하지만 계산 방식이 다르므로 구분하여 보고한다.
- AUROC 표에는 평가 이미지 수·음성 수·양성 수를, AUPRC 표에는 평가 이미지 수·양성 비율을 함께 기록한다.

### Sensitivity·Specificity

공통 이진 예측을 기준으로 다음을 계산한다.

| 항목 | 정의 |
| --- | --- |
| TP | 실제 양성을 양성으로 예측 |
| FN | 실제 양성을 음성으로 예측 |
| TN | 실제 음성을 음성으로 예측 |
| FP | 실제 음성을 양성으로 예측 |
| Sensitivity(민감도) | `TP / (TP + FN)` |
| Specificity(특이도) | `TN / (TN + FP)` |

민감도는 양성 클래스 Recall과 같다. 민감도·특이도는 `THRESHOLD`의 영향을 받으며, 분모가 0이면 `NaN`으로 표시한다.

## 6. U-multiclass의 3클래스 부가 분석

- 전체 정답과 모델 자체 예측 `y_pred`로 음성·양성·불확실의 분류 보고서와 3×3 혼동행렬을 계산한다.
- 클래스 순서는 음성 → 양성 → 불확실이며, 불확실 정답도 포함한다.
- 정답이 음성·양성인 항목에서 원래 3클래스 양성 확률 `y_prob[..., 1]`의 AUROC를 별도로 계산한다.
- 결과표에는 `3클래스 양성 확률 AUROC (부가)`로 표시한다.
- 세 실험의 비교에는 공통 이진 평가 결과를 사용하고, 3클래스 결과는 별도 부가 분석으로 해석한다.

## 7. 단일·복합 소견 비교

세 소견의 정답이 모두 음성·양성인 이미지만 사용한다. 하나라도 불확실 정답이 있으면 그룹 평가에서 제외한다.

| 그룹 | 실제 양성 소견 수 |
| --- | --- |
| 양성 소견 0개 | 0개 |
| 단일 소견 | 1개 |
| 복합 소견 | 2~3개 |

각 그룹에서 `y_true`와 `y_pred_binary`를 비교하여 다음을 계산한다.

- **세 소견 모두 정답 비율:** 이미지마다 세 소견을 모두 맞힌 비율.
- **소견별 판단 정확도:** 그룹의 전체 소견 판단 `이미지 수 × 3` 중 맞힌 비율.
- 그룹별 이미지 수를 함께 보고하고, 이미지가 없으면 지표를 `NaN`으로 표시한다.

단일·복합 구분은 대상 소견 3개 안에서의 구분이다. 양성 소견 0개가 다른 질환까지 없는 정상 영상을 의미하지는 않는다.

## 8. 시각화 및 오분류 분석

- 모든 실험에서 소견별 공통 이진 혼동행렬을 히트맵으로 표시한다.
- U-multiclass에서는 3클래스 혼동행렬도 추가로 표시한다.
- 단일·복합 그룹별 두 정확도를 막대그래프로 비교한다. 빈 그룹의 `NaN`을 성능 0으로 해석하지 않는다.
- 오분류 분석은 해당 소견의 불확실 정답을 제외하고, 공통 이진 예측의 FP·FN을 기록한다.
- 이미지 번호, 이미지 ID(`dicom_id`), 소견, 실제 정답, 모델 예측, 오류 유형, 양성 점수를 기록한다.
- 한 이미지에서 여러 소견을 틀리면 소견별로 각각 기록한다.
- 소견별 오분류 개수와 실제 정답 → 모델 예측 유형을 집계한다.

## 9. 결과 저장

저장 위치는 `evaluation/results/<실험 이름>/<학습 실행 폴더>/`이며, 학습 실행 폴더는 `MODEL_PATH.parent.name`을 사용한다.

| 파일명 | 저장 내용 | 적용 대상 |
| --- | --- | --- |
| `predictions_test.npz` | `y_true`, `y_prob`, `y_pred`, `y_score`, `y_pred_binary`, `dicom_id` | 모든 실험 |
| `auroc.csv` | 공통 AUROC 및 U-multiclass 부가 AUROC | 모든 실험 |
| `auprc.csv` | 공통 AUPRC(사다리꼴), 평가 수, 양성 비율 | 모든 실험 |
| `additional_metrics.csv` | Sensitivity, Specificity, AP | 모든 실험 |
| `finding_groups.csv` | 단일·복합 소견 그룹별 성능 | 모든 실험 |
| `misclassifications.csv` | FP·FN 사례 | 모든 실험 |
| `classification_reports_binary.json` | 소견별 공통 이진 분류 보고서 | 모든 실험 |
| `classification_reports_multiclass.json` | 소견별 3클래스 분류 보고서 | U-multiclass |
| `confusion_matrix_binary.png` | 공통 이진 혼동행렬 히트맵 | 모든 실험 |
| `confusion_matrix_multiclass.png` | 3클래스 혼동행렬 히트맵 | U-multiclass |
| `finding_groups.png` | 단일·복합 그룹별 성능 막대그래프 | 모든 실험 |
| `evaluation_info.json` | 실험·모델·데이터·학습 설정과 평가 기준 | 모든 실험 |

CSV는 `utf-8-sig`, JSON은 UTF-8로 저장한다. 평가 정보에는 평가 시각, 모델 경로, 테스트 CSV, 이미지 수, 저장 epoch, 학습·입력 설정, 소견·클래스 순서, 양성 점수 계산법, 이진 판정 기준과 평가 대상 선정 규칙을 기록한다.

현재 노트북은 한 번에 선택한 실험 하나를 평가·저장한다. 세 실험의 저장 결과를 합치는 통합 비교표는 별도로 구성해야 한다.

## 10. 결과 해석 시 확인사항

- 실험 간 동일한 테스트 이미지·정답·평가 대상과 판정 기준을 사용했는지 확인한다.
- 표본 수와 양성 비율을 함께 확인하고, `NaN`은 표본 부족 또는 평가 대상 부재 때문인지 구분한다.
- 공통 이진 지표와 U-multiclass 부가 지표의 예측 기준을 혼동하지 않는다.
- AP는 현재 모든 실험에서 공통 양성 점수를 사용한다. 과거 원본 3클래스 양성 확률로 계산한 AP와 기준을 구분한다.
- 소견별 macro 평균과 세 소견 간 평균을 구분하여 보고한다.
- 오분류 영상은 저장된 `dicom_id`로 원본 X-ray와 연결하여 분석한다.
