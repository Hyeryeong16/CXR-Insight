# 흉부 X-ray 소견 탐지 모델 평가

## 평가 목적
심비대·폐부종·흉수에 대한 예측 성능을 평가하고,
단일·복합 소견별 성능과 오분류 사례를 분석한다.

현재는 가짜 데이터 6장으로 평가 코드의 작동을 확인한다.
출력된 점수는 실제 학습된 모델의 성능을 의미하지 않는다.

## 라벨 및 데이터 규칙
- 소견 순서: 심비대 → 폐부종 → 흉수
- 클래스 코드: 0=음성, 1=양성, 2=불확실
- 세 소견이 모두 결측값인 이미지는 제외한다.
- 나머지 이미지의 결측값은 0으로 처리한다.
- 결측값에서 변환된 음성 라벨이 포함된다는 점을 결과 해석에 고려한다.

| 변수 | 내용 | 형태 |
|---|---|---|
| `y_true` | 실제 정답 코드 | (이미지 수, 3) |
| `y_prob` | 소견별 음성·양성·불확실 확률 | (이미지 수, 3, 3) |
| `y_pred` | 각 소견에서 가장 높은 확률의 클래스 | (이미지 수, 3) |

정답과 예측 데이터의 이미지 순서 및 소견 순서는 같아야 한다.

## 소견별 평가 기준
- 음성·양성·불확실을 모두 포함해 precision, recall, F1-score를 계산한다.
- 혼동행렬의 행은 실제 정답, 열은 모델 예측이다.
- 클래스 순서는 음성 → 양성 → 불확실로 고정한다.
- 계산이 불가능한 precision·recall·F1은 `zero_division=0`에 따라 0으로 표시한다.
- 정답 사례가 없는 클래스의 성능은 해당 데이터로 확인할 수 없으며,
  이 클래스의 0점도 macro 평균에 포함된다.

## 양성 AUROC 평가 기준
- 각 소견의 정답이 음성(0) 또는 양성(1)인 사례만 사용한다.
- 해당 소견의 불확실 정답(2)은 제외한다.
- 최종 예측 코드 대신 양성 클래스의 예측 확률을 사용한다.
- 정답이 음성·양성이라면 모델이 불확실로 예측했어도 평가에 포함한다.
- 음성과 양성이 모두 존재하지 않으면 계산할 수 없어 NaN으로 표시한다.

## 단일·복합 소견 비교 기준
세 소견의 정답에 불확실(2)이 없는 이미지만 사용한다.
실제 양성 소견 개수를 기준으로 다음 그룹으로 구분한다.

- 양성 소견 0개
- 단일 소견: 양성 1개
- 복합 소견: 양성 2~3개

그룹별로 다음 지표를 계산한다.

- 세 소견 모두 정답 비율: 이미지의 세 소견을 모두 맞힌 비율
- 소견별 판단 정확도: 그룹 내 전체 소견 판단 중 맞힌 비율

예측이 불확실이면 음성·양성 정답과 다르므로 오답으로 계산한다.
그룹에 이미지가 없으면 평가 지표를 NaN으로 표시한다.

단일·복합 구분은 대상 소견 3개 안에서의 구분이며,
양성 소견 0개가 다른 질환까지 없는 정상 이미지를 의미하지는 않는다.

## 오분류 분석 기준
- 정답 코드와 예측 코드가 다른 소견을 기록한다.
- 한 이미지에서 여러 소견을 틀리면 소견별로 각각 기록한다.
- 소견별 오분류 개수와 실제 정답 → 모델 예측 유형을 요약한다.
- 실제 데이터 연결 시 이미지 번호를 이미지 ID 또는 파일 경로로 대체한다.
